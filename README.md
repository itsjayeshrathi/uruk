# Uruk

**Uruk** is a fast and minimal command-line tool for **file encoding and decoding**.  
It begins with a **Huffman coding implementation** and will grow to support multiple algorithms, folder-level encoding, and multithreading.

---

## ✨ Features

- 📂 Encode and decode files using **Huffman coding**
- 🖥️ Simple and clean CLI powered by **Cobra**
- 🔧 Planned improvements:
  - Folder-level encoding/decoding
  - Multiple algorithms (LZW, RLE, etc.)
  - Multithreading and performance optimizations
